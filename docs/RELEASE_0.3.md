## 客户端与模型

新增独立侧栏页，按“工具 → 实际客户端 → 模型/模式”聚合现有规范化流水。

包含 Token、输入/输出、缓存读取比例、参考成本、价格覆盖、用量记录数、会话数、项目数、最近活动、模型在该客户端的 Token 占比。支持时间范围、工具、客户端、文本筛选及 Token/成本排序；点击模型可下钻到对应入口的记录。

同一模型跨入口分开计量；同一会话跨模型只计一个客户端会话。原始累计/会话汇总只算记录，不冒充单次 API 调用。未识别入口保留原始标签，未定价部分不当作免费。

该页导出 CSV / JSON 为统计摘要，不包含项目路径或会话标识。命令行 `usage-tracking clients` 输出所有已观测历史的客户端统计。

## 独立模型价格页
