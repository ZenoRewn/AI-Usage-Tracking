# Usage Tracking v0.4.2

Author: Zeno Ren

日期：2026-09-11。

## 菜单面板

- Codex / Claude / Copilot 的订阅额度由三行改为一排三张紧凑卡片，保留产品颜色与 Logo，增加已用比例环。
- Copilot 卡片直接显示已用 / 总 Credits，如 `70K / 10M Credits`；悬停可查看完整数字、剩余、采集/重置时间、下次自动刷新和失败信息。
- Copilot 和 Codex 卡片右上角有独立刷新按钮，只刷新该账户；查询中显示进度并禁止重复点击。已有顶部按钮继续刷新全部用量与账户。
- 多窗口额度显示有效窗口中最高的使用比例，无有效窗口时保留最高旧快照。各窗口明细均保留在悬停详情中，不相加、不把未知当作 0。
- 时钟标识表示含待更新快照；详情区分超过 15 分钟和服务返回的重置时间已过，避免把刚查询成功但重置时间异常误解为没有刷新。
- 保留 1 / 7 / 30 天用量表、菜单栏默认运行和用户刷新设置。

## 验证

- 52 项测试通过，新增覆盖最高窗口选择、旧窗口处理、Credits 紧凑/完整数字、Requests 单位、未知值和超过 100% 的显示。
- 临时 QA 窗口复用生产 MenuPopover、MenuQuotaCard、AppModel 与真实数据。已视觉核对三卡横排及 Credits 无截断；原生无障碍 Help 字段包含悬停详情。
- 在该生产组件上实际点击“刷新 GitHub Copilot 账户额度”，采集时间从 10:06:58 更新到 10:07:24（Asia/Shanghai），确认手动查询不等待自动间隔。
- QA 窗口只用于验证，不是正式 App 的启动界面，也没有修改外部工具的配置。
- Release 构建与安装包签名检查通过，v0.4.2 已在 Applications 启动；仍为 accessory 菜单栏模式，保留原有 30 分钟刷新间隔，临时 QA 进程已退出。

系统菜单栏直接点击仍受 CUA 工具限制；本次通过复用完整组件验证布局及真实刷新，未将该窗口描述为系统菜单弹层。Codex 当前登录方式和 Claude statusLine 连接的既有覆盖边界保持不变。
