# Usage Tracking v0.4.3

Author: Zeno Ren

日期：2026-09-11。

菜单面板增加“今日 Top 3 项目”，位于 1 / 7 / 30 天用量表下方。每项显示名次、项目名称、Token 总量、实际使用的工具 Logo 和各工具 Token。悬停显示项目路径、完整 Token、输入/输出、记录数与日期近似说明。

## 统计口径

- 本地时区今天零点到当前时间；未来记录和昨天记录不计入。
- 排名取项目跨工具 Token 总量最高的三项，不受主窗口筛选影响；少于三项时不补虚构项目。
- 沿用采集层归一化和去重后的记录，按规范项目路径分组；同名不同路径不合并，缓存和推理子集不重复相加。
- 自定义项目名沿用现有配置；未归属用量单独注明，不参与项目排名。
- 含会话汇总的项目以“≈”表示日期归属近似，具体来源在悬停中说明。
- 与菜单周期用量共用后台计算任务；跨日打开或持续查看菜单时更新统计日期，无需等待下一次日志扫描。

## 验证

58 项测试通过，新增覆盖跨工具排名与明细、时区零点/未来记录/跨日、同名不同路径、未归属用量、缓存子集、近似日期、空数据和 DST。

通过复用生产 MenuPopover 的临时 QA 窗口核对真实本机数据，今日三个项目按 Token 正确排序，自定义项目名生效，分工具 Logo/Token 和原生 Help 明细可见，面板无文字截断。直接操作系统菜单栏仍受 CUA 工具限制，视觉验证使用同组件窗口；该临时窗口不随正式 App 启动。

Release 构建与安装包签名检查通过，v0.4.3 已在 Applications 启动并保持 accessory 菜单栏模式，保留用户原有 30 分钟刷新间隔；临时 QA 进程已退出。
