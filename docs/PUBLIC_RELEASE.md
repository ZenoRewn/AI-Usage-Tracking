# Usage Tracking v0.5.2（Build 12）

Author: Zeno Ren

菜单额度区进一步收紧，并采用最初设计稿的深灰表面、薄荷绿与暖黄进度配色。

- 额度卡片高度约从 130pt 收到 100pt；主卡只保留比例、状态和重置提示，完整计数在悬停和点击详情中查看。
- 圆环长度反映实际已用比例；低于 80% 为薄荷绿、80–89% 为暖黄、90% 起为红色。品牌图标使用中性色；未知额度不伪造进度，旧快照用灰色标识。
- 深色面板与卡片使用有层次的中性灰，本机用量区减少边框，单位切换和工作台按钮统一为中性色。浅色模式保留对应的可读配色。
- 延续 Token / 参考 USD 切换、今日项目下钻、分组导航及 macOS 26 标题遮挡修复；用量、额度窗口与计价规则保持一致。

## 下载与升级

仅提供 Apple Silicon（arm64）的 DMG、ZIP 和 SHA-256 校验文件。需要 macOS 14+，无需 Rosetta；不提供 Intel 或 Universal 安装包。

推荐下载 `Usage-Tracking-0.5.2-arm64.dmg`。退出旧版后替换 Applications 中的 App，本机历史和配置继续保留。启动后在顶部菜单栏打开面板，选择“打开工作台”进入完整分析。

**当前为 ad-hoc 签名预览版，尚未完成 Apple Developer ID 签名和公证。** 首次下载打开如被系统拦截，请核对来源并遵循 [安装说明](https://github.com/ZenoRewn/AI-Usage-Tracking/blob/main/INSTALL.md) 中的 App 专属“仍要打开”步骤。

## 验证与范围

69 项本地测试通过，包含各工具的环长与使用比例一致性检查。原生样例用于界面验收；此证据不代表所有真实账户服务已经完成端到端验证。

额度查询需要相应 CLI 已安装并登录；Claude 配额依赖可选 statusLine 桥接，Copilot 部分入口需要本地遥测。Token 仅来自已采集记录，参考成本不等于订阅账单。
