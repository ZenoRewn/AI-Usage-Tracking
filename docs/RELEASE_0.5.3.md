# Usage Tracking v0.5.3（Build 13）

Author: Zeno Ren

修复 Copilot 近期低用量被误显示为灰环，以及状态栏面板外沿出现方框的问题。

- Copilot RPC 有时返回与查询时刻几乎相同的 `resetDate`。原逻辑把这个时间当成已过期窗口，导致新鲜用量也显示为旧快照。现在将其视为“下次重置时间待确认”，近期用量按真实比例和阈值着色。
- 保留原始服务时间；不清零、不补造下次重置时间。超过 15 分钟未更新或跨过真正的未来重置时刻时，仍显示旧快照。其他工具的过期规则保持不变。
- 未确认的重置时间不用于通知去重标识，避免随每次查询时间变化而重复提醒。
- 对无标题菜单宿主设置透明背景、20pt 连续圆角裁剪和系统阴影；玻璃内容也显式裁剪，保留 macOS 26/27 原生 Liquid Glass。标题栏工作台不应用菜单窗口样式。
- 原生验收工具增加实际状态栏入口与无标题面板，以及“重置待确认”样例，覆盖普通预览窗口之外的宿主行为。

## 验证

74 项测试覆盖近期读数/未确认重置时间、15 分钟过期、真正窗口跨期、其他工具规则、低比例环长，以及无标题窗口圆角与工作台隔离。先观察到缺失接口导致测试失败，再实现并通过。

已用修复后的模型执行真实 Copilot 只读额度查询：近期读数被归类为常规用量，重置时间单独待确认；不将私人账户读数写入公开测试或发行包。macOS 27 的原生无标题状态栏样例已检查圆角、玻璃材质和绿色低用量环；样例界面使用虚构数据。

发布前从干净检出运行测试、构建和 ARM64 打包；签名、DMG/ZIP 内容、公开下载校验及安装启动分别检查。当前仍为 ad-hoc 签名预览版，未完成 Developer ID 公证。更新保留本机数据与工具配置。
