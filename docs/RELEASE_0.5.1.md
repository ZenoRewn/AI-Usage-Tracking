# Usage Tracking v0.5.1（Build 11）

Author: Zeno Ren

Apple Silicon 预览版，仅提供 arm64 DMG、ZIP 和 SHA-256 校验文件。此版本包含 v0.5.0 的全部菜单交互改进，并进一步收紧额度区。

## 变化

- 额度卡片改为 36pt 品牌圆环与比例并排，固定内容高度约从 210pt 收到 130pt。取消“尚未获取 / 查看获取方式 / 查看详情”多行重复提示；额度未就绪时只保留状态和获取入口。
- 主卡保留重置提示与 Copilot 的绝对计数；完整窗口名称、窗口选择规则、来源、时间和刷新操作仍在点击详情中。
- 工作台侧栏分为“概览 / 用量分析 / 管理”，减少同级入口的扫描负担；标题适当缩小。
- 工作台使用紧凑窗口工具栏，并为 macOS 26 的标题区域保留避让空间，修复页面标题和操作按钮被工具栏遮挡的问题。
- 账户、价格、数据源和设置页不再显示通用的本地用量导出按钮，对应导出快捷键也禁用，避免误以为会导出当前账户额度。设置中明确标注的本机数据导出入口保留。
- 总览无记录工具显示“—”，不当作真实零用量；部分定价的参考成本直接标记，金额加估算符号。

统计、定价、额度查询与数据存储规则没有改变。图表下钻、项目表格排序、多账户作用域和通知持久化仍是后续改进。

## 验证与边界

- 本机 `swift test` 68 项通过；针对本轮排版、标签和导航变化，使用生产视图的原生样例进行渲染与交互检查。
- 原生样例覆盖深浅色、正常/无额度/未就绪/旧快照/异常状态，检查额度详情、数字明细和工作台导航。样例数据独立于用户数据，禁用采集器及账户 RPC。
- 发布前从干净的检出目录运行测试及 `Scripts/package-release.sh`，检查 App 和辅助程序均仅含 arm64，验证签名、ZIP、DMG 及校验值。
- 实际安装版从 `/Applications` 启动；菜单专用 App 的 UI 自动化读取存在限制，不能将样例交互检查声称为真实账户端到端验收。
- 当前仍为 ad-hoc 签名，尚未经过 Developer ID 公证。升级前退出旧版并替换 App，保留本机数据和配置。
