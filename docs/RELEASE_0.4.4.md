# Usage Tracking v0.4.4

Author: Zeno Ren

日期：2026-09-11。

“已观测用量”和“今日 Top 3”合并为紧凑的“用量概览”，保留今天 / 7 / 30 天并排对比。工具行每个时间范围只显示一个数字；项目改成一行名称、工具 Logo、总用量，减少重复标题、成本副行和分工具重复数字。完整用量、分工具明细及参考成本继续放在悬停详情中。

点击任意工具/项目用量数字或右上角单位按钮，可以让整块概览在 Token / 参考 USD 之间切换。Top 3 的数字同步切换，排序仍以 Token 为准，并在成本模式显示排序提示。项目成本沿用现有统一价格、自定义覆盖与缓存计价口径。

金额前“≈”为估算，“*”为部分用量已定价；未知价格显示“未定价”，未观察到记录显示“—”，明确的零单价保留 0 金额。不会把未知价格当作免费，也不会将账户 Credits 与参考 USD 混算。

## 验证

62 项测试通过，包括新增的 Token/成本显示、未定价/无记录/部分定价/明确零价、项目自定义价格与缓存计价覆盖测试。沿用生产组件的临时 QA 窗口用于布局与点击验证；它不属于正式 App 的启动流程。

- 同一宽度 440 点、同样包含三个今日项目的验证窗口，高度由 632 点降至 502 点，减少约 21%。
- 已实际点击工具 Token 切换到参考成本，再点击项目成本切回 Token，两个方向均同步更新整个概览；项目顺序保持不变。
- 已核对工具与项目数字的原生 Help，完整用量、参考成本、分工具明细及切换说明均可读取；两种显示模式无文字截断。
- Release 构建、安装包签名检查和安装版启动通过。v0.4.4 保持菜单栏模式，沿用用户的 30 分钟刷新设置；临时 QA 进程已退出。
