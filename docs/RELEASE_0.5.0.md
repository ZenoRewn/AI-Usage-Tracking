# Usage Tracking v0.5.0（Build 10）

Author: Zeno Ren

Apple Silicon 预览版。完成 CodeNotch 参考评审中的第一批菜单交互改进，仅提供 arm64 DMG 和 ZIP。

- 44pt 额度环、居中品牌、清晰的已用比例；以额度压力配色，保留文本状态。
- 主卡展示窗口、重置倒计时、缺失/旧快照/失败状态；Copilot 保留服务返回单位。
- 点击额度卡打开可阅读、可选择文本、可按 Esc 关闭的详情；独立刷新与恢复入口保留。
- Token / 参考 USD 用分段控件切换；数值点击打开明细，未知用量和未定价不会变成零。
- 今日 Top 3 项目可直接下钻到今天的精确路径记录，清除工作台旧筛选；跨日或已无记录时给出说明。
- 署名保留，营销版本与构建号同步更新；菜单保持原生深浅色适配。

沿用原有额度窗口选择、去重、定价、数据留存、采集与通知规则。贴边悬浮模式、工作台导航重组、账户作用域和通知持久化仍是后续工作。

`Scripts/build-menu-preview.sh` 构建隔离的原生样例窗口，复用生产视图；通过正常、无额度、旧快照、异常四种数据状态检查布局。示例目录和数据与用户真实采集目录分开，采集器及账户 RPC 禁用。
