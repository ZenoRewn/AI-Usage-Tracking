# Usage Tracking v0.5.2（Build 12）

Author: Zeno Ren

继续收紧菜单额度区，并按最初设计稿统一菜单配色。仅提供 Apple Silicon arm64 版本。

- 额度卡片高度约从 130pt 收到 100pt，采用 30pt 圆环；主卡保留已用比例、状态和重置提示，完整 Credits / Requests 计数移至悬停与点击详情。
- macOS 26/27 使用系统原生 Liquid Glass，较旧版本回退到系统超薄材质；最外层不使用实色覆盖。以 `#1C1D21` 轻度调色，卡片采用 `#26272D` 半透明叠层；品牌图标使用中性色。常规进度为薄荷绿 `#70CBB5`，接近上限为暖黄 `#F4B161`，高用量为红色 `#FF8585`。
- 环长等于已用比例；颜色低于 80% 为常规色、80–89% 为提醒色、90% 起为警示色。超过 100% 时保留真实数字、圆环封顶；未知额度不伪造进度，旧快照保持灰色。不同窗口不相加，主环继续选有效窗口中的最高已用比例。
- 本机用量区去掉重复卡片边框；单位切换和工作台按钮采用中性表面，降低紫色/蓝色装饰干扰。浅色模式保留可读的对应配色，工作台品牌颜色不受影响。

## 验证与边界

比例、阈值、未知值、旧快照及完整计数继续由既有模型和测试验证，并增加跨工具的环长一致性检查。原生样例用于检查正常、缺失、旧快照、超额、深浅色及切换交互；使用虚构数据，不查询真实账户。

本次原生样例在 macOS 27.0 上检查了 Liquid Glass、深浅色、单位切换与完整 Credits 详情；69 项单元测试通过。

发布前运行 `swift test` 和 `Scripts/package-release.sh`，确认两个可执行文件均仅包含 arm64，并检查签名、DMG、ZIP、下载校验及安装启动。本次只调整菜单显示，不改变采集、计费或通知规则。

当前仍采用 ad-hoc 签名，未完成 Developer ID 公证。覆盖安装保留本机历史和配置。
