# Usage Tracking v0.4.1

Author: Zeno Ren

日期：2026-09-09。

## 行为

- 冷启动仅显示菜单栏图标，不弹出主窗口、不显示 Dock 运行图标。
- 菜单面板中“打开工作台”或额度“详情”会打开主窗口并显示 Dock 图标。
- 关闭主窗口（红色关闭按钮或 ⌘W）后移除 Dock 运行图标，菜单栏和自动刷新继续工作。
- 最小化主窗口时保留 Dock 图标，以便恢复窗口；重复打开复用同一窗口。
- 重复启动仍保持菜单栏模式；通过菜单面板打开工作台。退出仍使用菜单面板电源按钮或 ⌘Q。

## 实现与验证

使用 LSUIElement 隐藏冷启动的 Dock 图标；AppKit 按需创建主窗口，随主窗口打开/关闭切换 regular/accessory 激活策略。后台采集由应用启动回调启动，移除其对 SwiftUI 主窗口 task 的依赖。兼容现有 macOS 14 最低系统要求。

47 项测试通过，包括真实 NSWindow 的懒创建、打开/关闭、重复打开和最小化恢复。Release 打包与安装包签名验证通过。

安装版已确认 LSUIElement 为 true，冷启动 activationPolicy 为 accessory，屏幕上没有主窗口；打开主窗口时切换 regular、关闭后回到 accessory，进程继续运行。后台已在未打开主界面时更新本地记录和 Copilot 额度。用户原有 30 分钟刷新设置保持不变。

顶部菜单栏图标已通过屏幕截图确认。当前 CUA 工具无法直接命中系统菜单栏坐标，菜单面板点击进入工作台未在最终安装包上完成自动操作验证；入口回调使用已测试的 WorkbenchController.show。保留既有菜单面板显示逻辑。
