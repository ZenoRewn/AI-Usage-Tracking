## 统一参考价格

依据用户指定的 [GitHub Copilot 官方价格页](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing)，内置 30 个模型、38 档价格，单位 USD / 百万 Token。覆盖 OpenAI、Anthropic、Google、Microsoft、xAI、Moonshot AI；离线可用，原有自定义价格优先。

- 默认对所有工具及历史记录应用该公价快照，表示当前公价折算，不表示当时账单、订阅实际支出或已套用折扣。
- Input、Cache Read、Cache Write、Output 分别计价；推理 Token 不重复加价。
- 对有明确单次调用数据的记录，按 200K / 272K 输入阈值选长上下文档。会话及快照汇总无法确定单次长度时，注明按标准档估算。
- 匹配常见模型 ID、点号/连字符版本名、已知提供方前缀及日期后缀；Claude fast mode 有独立价格。
- Gemini 3.6 / 3.7 / 3.8 Flash 的促销价截至 2026-12-31，到期后不会当作仍有效的价格沿用。
- 未列出的旧模型保留未定价，支持用户覆盖；总览、项目、模型、明细和导出使用同一计价逻辑。导出增加 costBasis / cost_basis。

可复核快照：[COPILOT_PRICES_2026-09-09.json](COPILOT_PRICES_2026-09-09.json)。快照包含来源 URL、获取日期及原始 HTML 哈希。导入脚本位于 Scripts/import-copilot-prices.py。

## 紧凑顶部面板

菜单栏入口采用单个图标。弹出内容将三家订阅压缩为三行摘要；每家最多显示两个额度窗口，其余进入详情。

下方同时展示 Codex / Claude / Copilot 的 1、7、30 天 Token 和参考成本。1 天为今天，7 / 30 天包含今天，按本地时区计算，独立于主窗口搜索和筛选。没有观测记录显示“—”；成本未完全覆盖时标星号，未知价格不算作免费。旧额度继续标“旧”。

面板使用相同 MenuPopover 视图的独立原生宿主窗口验证排版；未将系统顶栏点击自动化失败写作已通过。临时宿主及包含本地数据的旧截图不随产品发布。
