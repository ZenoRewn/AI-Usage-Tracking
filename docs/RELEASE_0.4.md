# Usage Tracking v0.4

Author: Zeno Ren

日期：2026-09-09。

## 更新

- 总览“投入最多的项目”和项目列表使用实际参与工具的品牌 Logo，多工具项目同时显示多个品牌。
- Codex / Copilot 账户额度支持自动刷新，后台失败在各自卡片内提示并保留快照。手动刷新与自动刷新共享防重叠机制；本地扫描不会覆盖刚获取的额度。
- Copilot 展示总额度、已使用、剩余 Credits；传统计费继续标注 Requests。采用 VS Code 对同一 RPC 字段的计量口径，不从 Token、USD 或套餐金额反推。详见 QUOTA_SEMANTICS.md。
- 模型价格页去掉显眼的 GHCP 来源链接，新增 Provider 筛选，可与模型搜索同时使用；来源和价格日期保留在内部目录及文档中。
- 刷新间隔支持默认、5 分钟、30 分钟、1 / 3 / 6 / 12 / 24 小时。默认本地 30 秒、账户 5 分钟；较长选项统一用于本地和账户。设置立即重算计划并持久化，兼容旧配置。
- 保留 Author: Zeno Ren、品牌来源声明、原有用量和计价方式。

## 现有边界

Claude 额度仍依赖 statusLine 实际更新；Codex 当前 CLI 登录方式可能不提供订阅额度。长刷新间隔不会延长快照有效期：超过 15 分钟或服务返回重置时刻仍提示旧快照。单账户监控不代表所有客户端和机器的 Token 流水已被采集。
